# 04 - Repository and Maintenance

## Repository role

This repository is a GPL-3.0 fork of `confygregit/ConfygreEmail` with substantial additional development.

## Source vs releases

Source code stays in Git. Generated Android and Windows binaries belong in GitHub Releases.

## Support

The canonical repository for this maintained fork is:

`https://github.com/inshalstratrum/ConfygreEmail`

Repository Issues are currently disabled at the GitHub settings level, so support links must not direct users to the upstream issue tracker as though it were this fork.

## Recommended GitHub settings

- enable Issues before advertising issue-based support;
- add repository topics for Gmail cleanup, Flutter, email management, Android, Windows, OAuth, and open source;
- add a concise repository description;
- keep branch/ruleset protections enabled;
- enable Dependabot and secret scanning where available.
