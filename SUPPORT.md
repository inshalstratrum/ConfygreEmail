# Support

Confygre Email is an active beta project.

## Before requesting help

Run:

```bash
flutter pub get
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test
```

For authentication problems, include the platform and the stage that failed, but never include OAuth tokens, client secrets, refresh tokens, or mailbox content.

For cleanup problems, state whether the action was:

- move to Trash;
- unsubscribe;
- permanent delete;
- Empty Trash.
